# Empty-start

## What This Is

这是一个面向 2026 TapTap 聚光灯 GameJam 的 Godot 游戏，当前工作名为 Empty-start，正式游戏名尚未提供。玩家填写主播名与粉丝团名、选择身份，在直播 PK 中用蓄力言弹命中话语并引发复读；普通关的矛盾击破、神谕与收藏结果最终汇入神降临和结局。

工程已实现身份开局、普通战斗及矛盾窗口的主要组合，神谕与休息已有数据入口。玩家神谕选择、真实奖励、休息继续、多关、终局与结局仍有缺口，当前完整流程与当前 checkout 运行结果均为 **UNVERIFIED**。

## Core Value

核心玩法能够实际运行，玩家能从新游戏走完一局到结局，并保有可继续集成和测试的稳定版本。

## Constraints

- **交付优先**：优先形成完整可玩流程，沿用现有组合与 API，按需求选择最小改动。
- **场景切换**：所有顶层页面/阶段切换由 SceneRouter 入口负责；子场景由所属场景组合。
- **数据归属**：PK、倾向、普通历史、复读历史和收藏分别沿用正式拥有者；UI 读取公开接口。
- **资源边界**：静态关卡 Resource 只读，继承内容在当前有效内容中组合，特性许可独立配置。
- **代码与日志**：新增核心逻辑使用简明中文注释；任务日志按系统名_任务卡_YYYY-MM-DD_log.md 命名并与实际实现提交。
- **验证预算**：集成以最小 runtime smoke 与人工验收为主；复用已有 tests，仅为明确高风险规则保留少量用例。
- **已知问题**：相关任务先读 known_traps.md；新可复现且长期有用的问题按既有格式记录。
- **计划状态**：onboarding 自主完成仅适用于本轮；后续 GSD 工作流保持交互模式，阶段尚未自动执行。
- **事实限制**：正式名称、截止日期、完整运行结果及设备性能目标缺证据，持续标为待定或 UNVERIFIED。
