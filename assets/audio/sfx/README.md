# 游戏音效来源

按正式17表与漫画直接使用的资源核对，均已列入结尾特别鸣谢。

- Kenney：Interface Sounds、Impact Sounds、Sci-Fi Sounds、RPG Audio；https://kenney.nl/assets 。本地分包License.txt与comic/README.md，CC0。
- ObsydianX：Interface SFX Pack 1，确认音；https://obsydianx.itch.io/interface-sfx-pack-1 。本地Ogg/README.txt声明CC0。
- Cassie-OrbitGames：Typewriter sounds，历史打字声已在AU-07停用，文件保留；https://opengameart.org/content/typewriter-sounds 。CC0。
- JaggedStone：Magic Spell SFX，蓄力和神降临；https://opengameart.org/content/magic-spell-sfx 。作者页CC0，magical/README.md有三个正式使用文件的原站哈希校验。

音乐另见../music/README.md：煉獄庭園/煉獄小僧使用作者自定义素材许可，与CC0音效分开说明。

AU-07：当前旁白改为Kenney的轻短字音；横幅补CC0划入/重击，真正击破使用同源混音。上述音效均不强制署名，游戏已有特别鸣谢属于自愿保留来源，不代表许可强制。可直接复制的本轮申报表见docs/Integration/音频素材声明_AU-07_2026-10-20.md。
