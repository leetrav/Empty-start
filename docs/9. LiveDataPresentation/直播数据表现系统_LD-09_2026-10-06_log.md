# 直播数据表现系统 LD-09 任务日志（2026-10-06）

## 1. 本次任务

在当前游戏入口展示观看、点赞、评论和粉丝四项直播数据，并在数据变化后刷新数字。

## 2. 修改文件

- `ui/live_data/live_data_hud.tscn`、`ui/live_data/live_data_hud.gd` 与 `.uid`：新增复用型 HUD；只读取当前周目的 `SaveData.live_session`，订阅 Resource 变化并刷新四个数字标签。
- `core/live_data/live_session_data.gd`：四个计数属性变化时调用 `emit_changed()`，为表现读取方提供更新通知。
- `scenes/sandbox/sandbox.tscn`：在当前 `SceneRouter.goto_game()` 指向的 Sandbox 挂载 HUD。
- `docs/9. LiveDataPresentation/README.md`：记录 HUD 场景、数据读取和 Resource 更新通知方式。

## 3. 当前能力

Sandbox 右上角显示观看人数、点赞数、评论数和粉丝数。HUD 初始化时读取当前 SaveData 的四项值；LiveSessionData 任一计数变化时发出 `changed` 信号，HUD 重新读取四项数值。没有当前周目数据时显示 0。UI 本身不修改直播数据。
