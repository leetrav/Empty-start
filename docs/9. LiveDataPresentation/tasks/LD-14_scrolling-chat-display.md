# LD-14 直播评论从下向上滚动显示

**状态：待开发 · 普通直播评论流**

## 开始前阅读
- `AGENTS.md`、`project.godot`、本系统 README 及最新完成日志
- 现有 `LiveDataHud`、`Sandbox`、源表导出器与主播粉丝牌资源
- 前置或接口参考：LD-13、现有 LD-09/INT-03 HUD

## 当前实现与复用入口
`ui/live_data/live_data_hud.tscn` 已有四项无 Panel 的 `RichTextLabel` 指标；INT-03 采用左右各 `448×520` 的直播数据区域，数字靠边显示。

## 本卡唯一功能
直播评论从下向上滚动显示。

## 触发条件
玩家或对手侧收到一条经 LD-13 抽出的直播评论展示请求时。

## 应发生的行为
在现有双侧直播数据表现区为评论创建轻量显示行，展示 `用户名：正文`，让新评论从评论区域下方进入，按配置速度平稳向上滚动。评论可换行，始终裁剪在各自评论可视区域内，到达显示区域外后结束该显示行。显示行数量、滚动速度、文字大小与间距可调；适配两侧直播区宽高、窗口/全屏缩放及现有四项直播指标的占位，并继续使用现有无大面板、仅文字与图标的 HUD 风格。评论行输入可穿透，战斗操作保持正常。

## 验收
左右 `448×520` 区域有独立评论滚动；每条评论从下进入、向上移动并在出界后消失；长句适当换行且在本侧裁剪；四项数据、昵称和评论均可读；PC 1920×1080、1280×720 与 Android 画面无明显重叠或眩晕。
