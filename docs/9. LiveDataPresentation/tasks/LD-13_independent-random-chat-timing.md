# LD-13 玩家与对手直播评论分别随机刷新

**状态：待开发 · 普通直播评论流**

- `AGENTS.md`、`project.godot`、本系统 README 及最新完成日志

- 前置或接口参考：LD-12；现有 `LiveSessionData`、LD-05

## 当前实现与复用入口
`LiveSessionData.comment_count` 已由 LD-05 按实际弹幕及复读生成累计，承担现有统计职责；新增评论流属于观感模拟。

## 本卡唯一功能
玩家与对手直播评论分别随机刷新。

## 触发条件
玩家或对手直播间进入可展示评论的战斗状态时。

## 应发生的行为
为玩家侧、对手侧分别维护独立的随机评论刷新时钟。每次根据该侧可用的 LD-12 表候选、可配置的粉丝比例及条目权重抽取一条 `username + text + audience_type`，输出给对应侧的评论展示入口。刷新间隔、粉丝比例与同屏目标数量作为可调表现参数；按温和、具有随机停顿的节奏作为默认设置。两个直播间分别计算自己的抽取结果。每条可见模拟评论只属于显示事件，现有 `LiveSessionData.comment_count` 的业务统计保持由 LD-05 的真实弹幕生成事件驱动。

## 验收
左右评论顺序和出现间隔独立变化；抽取字段来自配置表；粉丝和路人都可出现；刷新间隔和粉丝比例调整后表现随配置改变；连续显示多条模拟评论，LD-05 的累计结果保持由原统计入口决定。
