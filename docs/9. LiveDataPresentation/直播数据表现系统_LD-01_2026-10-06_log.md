# 直播数据表现系统 LD-01 任务日志（2026-10-06）

## 1. 本次任务

建立本场直播观看、点赞、评论、粉丝四项数据状态，并让本场数据随当前周目保存。

## 2. 修改文件

- `core/live_data/live_session_data.gd` 与 `.uid`：新增 `LiveSessionData` Resource，提供四项计数字段和 `initialize_session(initial_fan_count)` 初始化入口。
- `core/save/save_data.gd`：新增 `live_session` Resource 字段，由当前 SaveData 持有，供跨场景读取并复用现有存档流程。
- `docs/9. LiveDataPresentation/README.md`：记录数据字段、持有位置、初始化行为和本系统用途边界。
- `docs/System_Collaboration.md`：说明 UI / 休息展示从 `SaveData.live_session` 读取四项数据。

## 3. 当前能力

本周目可通过 `SaveManager.data.live_session` 读取 `viewer_count`、`like_count`、`comment_count`、`fan_count`。调用 `initialize_session(initial_fan_count)` 会将本场观看、点赞和评论置零，并写入当前粉丝数。直播状态 Resource 随 SaveData 跨场景保存，四项数据仅用于表现与展示。

新周目的粉丝字段默认值暂为 0；LD-02 会接入正式起始粉丝配置和开播观看人数计算。
