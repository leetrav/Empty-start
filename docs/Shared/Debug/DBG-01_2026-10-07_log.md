# DBG-01 游戏内 DEBUG 面板日志

日期：2026-10-07

分支：`codex/dbg-debug-panel`，基于最新 `origin/main`（`05d61a7`）。

## 本卡实现

- 新增 `ui/debug/debug_panel.tscn` 与 `ui/debug/debug_panel.gd`，在 Sandbox 中以高层 CanvasLayer 覆盖普通 HUD 和 PauseMenu。
- `project.godot` 新增 `debug_panel` Input Map，绑定 F3；面板使用 `PROCESS_MODE_ALWAYS`，切换时不暂停 SceneTree。
- Sandbox 注入状态读取与调试动作入口；面板每 0.25 秒读取快照，不保存 PK、Tier、直播数据、倾向或弹幕数量副本。
- 增加系统最小调试接口：HitResolution 设置 PK 并复用最终 PK 信号；TendencyState 只改本场暂存；AttackChargeInput 暴露真实蓄力按住状态；BarrageArea 提供当前数量、保留生成状态的清屏、立即单批生成和恢复生成入口。
- 更新 Shared、HitResolution、CombatAttack、BarrageGeneration、ThreeTendencies 正式文档。

## 面板 Scene Tree

```text
DebugPanel (CanvasLayer, layer 20, PROCESS_MODE_ALWAYS)
├── Background
└── CenterContainer
    └── PanelContainer
        └── MarginContainer
            └── ScrollContainer
                └── Content
                    ├── 当前状态（关卡、主播、阶段、PK、Tier、攻击阶段）
                    ├── PK 快捷值
                    ├── 弹幕与战斗操作
                    ├── 我方直播数据输入
                    └── 本场倾向输入
```

## 状态来源与操作入口

| 面板内容 | 真实拥有者 / 入口 |
| --- | --- |
| 当前关卡与对手主播 | `LevelRunState.get_current_level_profile()` |
| 我方主播 | `SaveData.streamer_name` |
| 玩家 PK | `HitResolution.get_player_pk()` |
| Tier | `CombatStage.get_current_tier()` |
| 攻击阶段、蓄力状态 | `AttackChargeInput.get_attack_phase()`、`is_charge_held()` |
| 普通 / 复读弹幕数量 | `BarrageArea.get_current_barrage_counts()` 读取现有视图 |
| 直播四项 | 当前 `SaveData.live_session` |
| 本场三项倾向 | 当前 `SaveData.tendency_state` 的 attempt 值 |
| PK 快捷设置 | `HitResolution.set_player_pk_for_debug()` → `apply_player_pk_delta()` → CombatStage / HUD |
| 重新开始 | `Sandbox.restart_current_attempt()` |
| 清屏 / 立即生成 / 停止 / 恢复 | `BarrageArea` 与 `RepeatDelayQueue` 公开入口 |
| 设置直播数据 / 倾向 | `LiveSessionData` 属性 setter、`TendencyState.set_attempt_tendencies_for_debug()` |
