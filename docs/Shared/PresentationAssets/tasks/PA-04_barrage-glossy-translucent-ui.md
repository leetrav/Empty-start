## 本次已确认的美术需求（第一轮）

### 1. 风格参考
- 参考作品：《如龙0》电话交友俱乐部的消息板视觉（以策划讨论时提供的截图为参考）。
- 要提取的特征：**明亮、光滑、略带厚度的塑料玻璃板质感**，具有可辨认的反光与边缘高光。
- 只参考材质与静态外观；生成方向、运动、缩放和遮挡行为另由程序需求确定。

### 2. 基础底板
- 每条普通弹幕使用**圆角矩形底板**。
- 底板为**半透明**，叠在其他弹幕或画面上时，后方内容仍可透出。
- 材质呈现**明亮的塑料玻璃光泽**；边缘需要有体现表面反光或厚度的高光 / 轮廓。
- 底板尺寸能够适配实际显示的弹幕文字；具体留白、圆角半径、边框宽度尚未确定。

### 3. 颜色可调
- **尚未确定主色，粉色仅属于参考截图，不作为当前配色要求。**
- 底板填充色、透明度、边缘色与高光颜色应可方便地调整；尽量通过 Godot 的 Style / Theme / Shader 参数或可配置 Resource 管理。
- 更换色彩方案时，基础结构与材质风格保持可复用。

### 4. 面向高密度显示
- 设计时考虑**数百条弹幕同时可见**的情况；策划预计可能达到 500 条或更多。
- 静态材质在大量透明叠层后仍应具备可辨认的视觉特征，避免高光 / 边框叠加后大面积过曝。
- **500 不是本卡规定的数量上限、验收帧率或性能目标。** 实际生成上限与性能压测由程序需求单独讨论确定。

## 预期实现形式（程序美术方向）
- 优先使用 Godot 原生视觉能力，例如 `StyleBoxFlat`、`Theme`、`_draw()`。
- 需要额外亮面高光或细微材质细节时，可使用轻量 Shader；也允许通过 SVG 生成可复用图形并导出透明 PNG。
- 以可调参数驱动颜色与材质，优先复用现有弹幕显示入口；具体节点结构在派工前根据已确定的整套视觉需求选择。
- 具体视觉数值、Shader 做法及资源格式，等待原型试验后确定。
