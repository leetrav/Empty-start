## 本次任务

### 1. 言弹造型
- 将玩家发射的言弹表现为**一眼可辨认的漫画风实体子弹**。
- 使用**漫画色块 + 简洁高光 + 短促速度线**的统一视觉语言。
- 以几何形状构成清楚的弹头、弹身和尾部，使用鲜明色块与轮廓凸显体积和运动方向。
- 在弹体表面加入少量简洁高光，形成轻微的立体感。
- 将主体尺寸、配色、轮廓和高光参数设为可调。

### 2. 飞行路径与单发多结果
- **发射起点是释放瞬间的准星中心**。实体言弹从该位置出现，朝本发释放快照中命中的目标方向飞行。
- 当一发快照包含多条有效目标时，仍只绘制**一颗言弹**：使用与准星中心最接近的一条快照目标作为可见飞行落点；到达后由既有多目标结果为每条实际命中弹幕分别播放 PA-06 反馈。
- 如本发没有命中目标，言弹从准星中心作短距离的落空飞行后消隐，并衔接 PA-09 的落空提示。
- 飞行时长沿用既有 AttackChargeInput 的时间；飞行轨迹和显示落点只控制动画，不重新计算或改变已冻结的命中集合。

### 3. 飞行速度线
- 飞行时在弹体后方显示短促的漫画速度线，强调攻击方向和冲击感。
- 让速度线与子弹位置、方向及攻击节奏同步。
- 支持集中调整速度线的长度、粗细、透明度与出现时间。

### 4. 现有攻击流程接入
- 使用现有攻击释放、飞行和到达阶段驱动言弹视觉。
- 发射时呈现完整弹体，飞行中保持稳定清晰的子弹轮廓，到达时衔接 PA-06 的相应命中反馈。
- 保持现有目标、时间和结算行为继续正常运行。

### 5. 程序美术制作
- 优先使用 Godot `_draw()`、`Control` / `Node2D`、Tween 或 AnimationPlayer 实现子弹形状、高光和速度线。
- 如需可复用纹理，使用 SVG 生成透明 PNG。
- 统一管理相关视觉参数，便于后续调整。

## 验收
- 实际战斗中能看到漫画风实体子弹，具备清楚的弹头、主体及尾部轮廓。
- 漫画色块、简洁高光、短促速度线三项特征均可辨认。
- 言弹从准星中心飞向本发目标；一发命中多条弹幕时只出现一个飞行弹体，但按现有结果产生多处命中反馈；落空也有对应短程飞行。
- 到达后正确衔接 PA-06 命中反馈，现有战斗运行正常。
- Godot 实际画面与 Output / Debugger 验证通过。
