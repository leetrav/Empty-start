## 本次任务

### 1. T0 → T1：CRT 电视接通信号
- 在对手直播画面由未连线转为接入时，播放一次**老式显像管电视“啪”地打开**的短促效果；参照《不予播出》的电视直播接入质感。
- 视觉动画按以下顺序组成：暗屏上出现**明亮水平细线** → 水平线快速向上下展开为画面 → 同时出现短暂**CRT 扫描线、噪点和少量横向信号错位 / 扭曲** → 接通瞬间短闪、图像稳定清晰。
- 打开瞬间叠加一个**漫画式冲击符号 / 线条图形**，优先沿用项目现有受击漫画字的手绘、不规则粗细笔触语言。
- 画面接通后显露已有的对手立绘，随后衔接既有气泡对白展示。
- 使用轻量 Shader、程序绘制及 Tween / AnimationPlayer 组合实现；扫描强度、水平线亮度、失真幅度、闪烁强度和整体时长可调。

### 2. 普通升档：半透明上箭头
- 在 T0～T5 普通升档的**清屏完成后**，于**中央弹幕战斗区正中**绘制一个半透明 **↑ 上箭头**。
- 图形以几何轮廓或程序绘制构成，轮廓与填充清晰；支持颜色、线宽、尺寸和透明度调整。
- 动画顺序：**迅速弹出 / 放大 → 轻微向上冲 → 短暂停留 → 上移淡出**；随后由已有阶段流程恢复新档弹幕。
- 升档提示只使用箭头图形，保持居中、半透明的视觉基调。

### 3. 普通降档：半透明下箭头和震屏
- 在普通降档时，于**中央弹幕战斗区正中**绘制一个半透明 **↓ 下箭头**。
- 动画顺序：**短促弹出 → 随战斗区一次震动 → 轻微下沉 → 淡出**。
- 同步复用或衔接 CS-16 的战斗区域短时震动表现；场上弹幕在演出期间继续存在和运动。
- 下箭头使用与升档相配套的视觉规格，颜色、线宽、尺寸和透明度可调；降档提示只使用箭头图形。

### 4. 通用呈现与视觉参数
- 优先使用 Godot `_draw()`、`Control` / `Node2D`、Tween、AnimationPlayer、轻量 Shader 等原生表现方式。
- 提供可集中修改的箭头色彩 / 不透明度 / 尺寸、出现与淡出时长、位移幅度、CRT 扫描与信号干扰强度、漫画符号尺寸 / 偏移，以及震动显示强度。
- 对照 PA-10 的后期视觉统一方向，让三种演出能与正式字体、主播画面、弹幕材质和手绘漫画符号搭配。
- 从现有阶段状态与场景协调入口驱动对应表现，保持 Windows / Android 适配以及暂停、战斗结束时的画面状态正确。

## 验收
- T0→T1 对手接入时，画面出现一次**亮线展开、短暂扫描 / 干扰、闪亮接通、漫画冲击符号**，随后顺利显示对手立绘和气泡对白。
- 每次升档在清屏完成后，中央战斗区显示**半透明向上箭头**并短促上移淡出，再正常回到新档弹幕。
- 每次降档保留原弹幕，中央战斗区显示**半透明向下箭头**并伴随短促震屏，随后恢复正常视觉状态。
- 升降档箭头不依赖文字，且单次跨档切换能以最终状态显示正确方向。
- 所有演出的主要视觉参数可调；在实际 1920×1080 游戏画面和 Android 适配画面中位置、比例、透明度和可读性正确。
- Godot 实际运行画面及 Output / Debugger 验证通过。
