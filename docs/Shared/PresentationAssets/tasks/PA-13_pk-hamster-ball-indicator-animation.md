## 本次任务

### 1. PK 条上的仓鼠球位置
- 将仓鼠球作为**一枚可移动的图像指示器**叠放在现有 PK 条上，中心对齐玩家 PK 当前进度对应的位置。
- 玩家 PK 为 **0%** 时球心在条形轨道一端，**100%** 时在另一端，按现有 PK 条玩家占比增长方向线性映射；50% 对应中间。进度条宽度和 HUD 缩放变化时同步对齐实际可见轨道。
- 读取 **已有 `player_pk`** 更新目标位置，使用短促平滑的插值 / Tween 过渡。PK 持续回拉与发射得分时都能跟随；位置来源与原进度条相同。

### 2. 仓鼠球滚动
- 仓鼠球沿 PK 条横向移动时**伴随自身旋转**，让它看起来像一个圆球在条上滚动前进。
- 球的旋转方向根据**实际显示位移方向**变化，滚动速度与可见移动速度协调；位移越快滚动越明显，移动停止时转动停止。
- 素材以球心为旋转中心；滚动动画与位移同步，减少滑行错觉。旋转倍率、位移过渡时长、指示器尺寸、相对轨道垂直偏移可调。

### 3. 默认表情和降档表情
- **通常显示笑脸** `pk_indicator_01.png`：待机、持续 PK 变化、玩家得分和升档都使用这张图。
- **仅当实际发生降档事件时**，临时切成**惊慌脸** `pk_indicator_02.png`，并播放本卡第 4 节降档动效；演出结束恢复笑脸。
- PK 数值下降、敌方持续回拉、进入较低 PK 百分比区间时，**如果没有实际降档事件**，仍显示笑脸。表情变化对应阶段事件，不是简单的 `player_pk < 某阈值`。
- 重开 / 新场景进入时初始化为笑脸，并按当前 PK 实际值定位。

### 4. 升档 / 降档时的球体动作
- **升档**：球保持笑脸，在 PK 条当前位置短促**上蹦 → 空中轻微抖动 / 旋转 → 落回轨道并回弹**；呈现高兴、振奋的跳跃感。
- **降档**：球短暂切成惊慌脸，在 PK 条当前位置**快速抖动 → 惊跳 / 弹起 → 落下轻微弹性震颤**，结束后恢复笑脸。
- 升降档动画都叠加在当前位置的持续滚动之上；跳跃的垂直偏移和抖动使用球本身的局部表现，不影响 PK 条轨道或 PK 数值。与 PA-11 的中央箭头 / 战斗区震动共用已有阶段变化事实。
- 动效可集中调整：跳跃高度、起跳 / 落地时间、抖动幅度与频率、回弹程度、惊慌表情停留时长。阶段短时间内连续变化时可中断旧局部动效并按最新阶段重播；最终回到 PK 对应的位置与笑脸常态。

### 5. 接入与适配
- 优先在现有战斗 HUD PK 区域复用 `TextureRect` / `Control` 与 Tween、AnimationPlayer 实现；位置轨道与当前 `ProgressBar` 的实际绘制矩形一致。
- 用真实 `refresh_pk()` 的输入更新位置；由现有阶段通知触发升降档动画。必要时把**阶段方向（上升 / 下降）**传给 HUD 的表现入口，基于上一状态与新状态比较触发一次动作。
- 画面宽度、缩放、窗口 / 全屏 / Android 变化后正确重算轨道端点，球心不越出目标轨道。
- 在 PK 阶段切换和场景生命周期期间保持素材切换与动画的稳定显示；所有可调参数集中在实际的表现组件中。

## 验收
- 玩家 PK 从 0% → 50% → 100% 时，仓鼠球沿 PK 条从起点经中点到终点；反方向变化时跟随返回。
- PK 持续回拉或命中得分时，仓鼠球随真实 PK 变化**移动并同步自转**；静止时停止旋转。
- 默认与升档期间显示笑脸；**仅发生降档时**短暂显示惊慌表情，完成抖动 / 惊跳 / 落地后恢复笑脸。
- 升档时笑脸仓鼠球明显蹦跳回弹；降档时惊慌仓鼠球明显抖动与蹦跳。滚动与跳跃可以同时发生，视觉动作不破坏 PK 轨道位置。
- 连续升降档、重开、窗口缩放与暂停后，仓鼠球没有错误表情或越位；1920×1080 和 Windows / Android 运行画面验证通过，Godot Output / Debugger 无新增错误。
- 本卡的完成依据是**真实场景录屏 / 画面和输出日志**，不以仅能加载两张 Texture2D 为完成标准。
