# Shared PresentationAssets PA-03 任务日志

## 1. 本次任务

将 PA-02 已入库并接好 Resource 的素材接入 Sandbox 主战斗 HUD；保持 1920×1080 设计画布和现有玩法区域尺寸。

## 2. 修改文件

- `scenes/sandbox/sandbox.tscn`：在左右主播信息区增加粉丝牌显示槽；在现有 448×432 主播画面区域增加背景与立绘 TextureRect 显示层，没有调整左右区、中央弹幕区或底部交互区尺寸。

- `scenes/sandbox/sandbox.gd`：从 `PresentationAssetConfig` 读取主角资源，从当前 `LevelProfile` 读取对手资源并交给 HUD。
- 本日志：记录资源接线、保留占位和运行验证结果。

## 3. 实际接入资产

- 玩家立绘：`assets/characters/chr_player_hamster_idle.png`，读取 `PresentationAssetConfig.player_streamer_portrait`。
- 玩家直播背景：`assets/environment/bg_player_live.png`，读取 `PresentationAssetConfig.player_live_background`；放在主播立绘区域底层，按当前区域比例铺设。
- 玩家粉丝牌：`assets/ui/ui_player_fan_badge.png`，读取 `PresentationAssetConfig.player_fan_badge`，显示在玩家信息区。

- `project.godot` 已应用 `ui/theme/base_theme.tres`；PA-02 没有交付字体文件，沿用当前 Theme 字体。

`bg_player_room_1.png` 属于房间背景，本次主战斗 HUD 没有使用它。PA-02 当前没有观看、点赞、评论、粉丝四种正式指标 ICON，也没有 PK、Tier、准心和蓄力条专用美术；这些位置继续使用原有文字 / Emoji / 样式占位，没有生成替代素材。
