# Audio AU-01 任务日志（2026-10-06）

## 1. 本次任务

建立可编辑的音频事件 Resource 配置，并让 `AudioManager.play_event(event_id)` 按事件类型复用既有播放器与 Bus。

## 2. 修改文件

- `core/audio/audio_event.gd` 与 `.uid`：新增事件 Resource，保存稳定 ID、Music / SFX / UI 类型和 `AudioStream`。
- `core/audio/audio_event_config.gd` 与 `.uid`：新增集中事件列表 Resource 和按 ID 查找入口。
- `data/shared/audio_event_config.tres`：集中配置 11 个当前稳定事件 ID，均配置类型和有效音频资源。
- `core/autoload/audio_manager.gd`：新增 `play_event(event_id)`，按类型路由到现有音乐播放器或 SFX / UI 播放池。
- `assets/audio/sfx/interface/confirmation_001.ogg`、`License.txt`：从仓库已有 Kenney 界面音效包提取确认音和 CC0 授权文本，供 UI 事件使用。
- `docs/Shared/Audio/README.md`：记录配置路径、事件 ID、占位素材替换规则和音乐素材现状。

## 3. 当前能力

玩法系统可通过 `AudioManager.play_event(&"attack_fire")` 等稳定 ID 请求播放。Music 类型会调用现有 `play_music()`；SFX 和 UI 类型分别使用对应播放池与 Bus。配置中的 11 个事件 ID 为 `attack_charge`、`attack_ready`、`attack_fire`、`hit_normal`、`hit_trap`、`tier_up`、`contradiction_start`、`contradiction_break`、`oracle_confirm`、`divine_descent_start` 和 `divine_descent_lock`。

当前事件引用的是临时音效；`oracle_confirm` 使用 Kenney CC0 界面确认音。仓库暂无正式音乐文件，因此暂时没有 Music 类型事件配置。正式素材到位后只需替换事件 Resource 的 `stream`。
