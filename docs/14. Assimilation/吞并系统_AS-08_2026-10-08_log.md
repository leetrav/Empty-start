## 3. 当前能力

- 真正击败登记成功时保存该关的主播 ID，随后每次词库 / 特性成功登记立即成为该来源已提交新增内容。
- 跨来源重复的稳定词库 / 特性保留最初归属；后一个来源只返回自己实际新增的条目。
- 同关同主播读取返回包含来源 ID、词库 ID / 权重、特性 ID 的快照；无新增或来源不匹配返回 `{}`。
- 总量读取始终返回当前周目全部继承词库 / 特性的独立副本。读取和修改返回值都不发奖或改变保存数据。
- 来源记录随所属 `SaveData.assimilation_data` 存读，重复读取保留同一场事实。
