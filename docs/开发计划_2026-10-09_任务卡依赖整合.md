# GameJam 当前任务卡整合与依赖顺序（2026-10-09）

> **状态：现行派工入口 · 仅整理文档。**
> 当前 `main` 的任务目录共有 **302 张**任务卡（含已完成基础系统、历史暂存卡、集成任务和程序美术任务）。本表集中管理最新待开发、需联调、数值待定和候选打磨任务；基础系统已完成的卡与实际完成日志继续保留作接口依据。

## 一、统一口径（优先于历史需求讨论片段）

1. **前景话语**：普通话语与挂有 1 项或多项兼容特性的特殊话语，是同一种普通实例，共用当前 Tier 的少量前景同屏名额；从现有话语池随机抽取并按原有生成频率补位。T1=10、T2=13、T3=16，T4=19、T5=22 是当前逐档增加 3 条的规划，T0 待填。
2. **复读**：沿用当前 Tier 每次普通命中产生 3/6/8/12/15/20 条的配置，并使用独立的待生成容量与同屏上限。普通复读从左向右低速移动，按生命期渐隐，灰色、零文字描边、始终最低层。普通复读有圆角气泡的美术设计。
3. **特殊话语与遮挡**：一条实例挂两项特性也仅算一个前景名额、一个特殊实例名额；遮挡实例在最高层慢速移动。整发范围内存在遮挡时，整发按已有落空惩罚结算并保留区域全部实例。假复读属于带 `fake_card` 特性的前景普通话语，使用鲜艳椭圆气泡和清晰文字描边；与底层灰字复读分别处理。
4. **Tier 与对手**：每次升档完整提交本发后清屏并清空旧普通复读待生成队列；降档统一震屏、弹幕保留并自然回落。降到 T0 对手离线并显示搜索状态；降到 T1 对手嘲讽。T2～T5 每档每场首次达到时各随机抽取一次反击，按当前 Tier 激活已抽结果，降档暂停高档技能后续触发，回升恢复原结果。
5. **T6 / Paradox**：普通战斗 Tier 是 T0～T5；满 PK 后进入独立 T6 矛盾阶段，6 句（1 真、5 假）由出现起即可射击，运动一段时间后沿速度曲线减速停止。已有 10 秒窗口、一发正式射击机会继续使用。
6. **战斗布局与体验**：1920×1080 三列，中央顶部 1024×72，INT-06 计划将弹幕区扩至 1024×1008，左下浮层仅放鼠标左键和 ESC 操作 ICON。蓄力状态依旧由 CombatAttack 提供，美术通过 PA-08 的环形准心反馈接入。单场完整普通战斗目标约 **2～4 分钟**，具体阈值、收益、回拉待后续函数建模。

## 三、关键依赖链

- **Tier 容量**：`CS-24 → BG-16 → BG-34/BG-36`；`LC-12 → BG-35`。
- **特性选择**：`CS-28 → CS-29 → BG-41`，同时 `BG-35 → BG-41`。候选技能池到位后启动 CS-28；实际技能触发由对应系统消费 CS-29 的有效技能集合。
- **运动**：`BG-40 → BG-20/21/22/23 → BG-39`；`BG-24 → BG-18 → BG-19`。
- **层级**：`BT-14` 遮挡最高层与 `RP-21` 复读底层可分别实施，然后 `BG-25 → BG-26` 管理普通前景随机层级。
- **文字**：`BG-28 → BG-29/BG-37`；`BG-37 + RP-19 → RP-20`；PA-04 基于已能区分不同文本类型的展示接口实施普通美术。
- **结算**：已有 `CA-14 → CA-15 → BG-38` 回归；`HR-16 → HR-17` 分别限幅正负贡献并合算整发 PK。
- **阶段**：`CS-18 → CS-14 → CS-15`；T0 匹配 `CS-20 → CS-21 → CS-22 → CS-23`；通用震动 `CS-16` 与离线 `CS-26` / 嘲讽 `CS-27` 可叠加。
- **矛盾**：`CB-13 → CB-14`；CS-25 只负责 T6 HUD 状态标记，可与 CB-13 并行。
- **表现**：`INT-06` 更新真实场景矩形，PA-03 作布局复验；`PA-04 → PA-05 → PA-06 → PA-09 → PA-10`。PA-06 命中材质、PA-09 局部与主播旁结果提示分别负责各自演出。
- **独立小卡**：`LD-11` 基于现有 LiveDataHud 将 1000 显示为 1.0k，展示文本与原始整数分离；可并行。
