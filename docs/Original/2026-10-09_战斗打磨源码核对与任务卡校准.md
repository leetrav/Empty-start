## 实际已存在的功能
1. `NormalSpeechSelector.select_next_normal_speech()` 按关卡倾向比例和单句权重从关卡词库选句。
2. `BarrageArea._spawn_normal_batch()` 与 `SpawnTimer` 按倍率分批生成；普通容量占满即暂停 Timer，实例离场释放名额后恢复。
3. `BarrageCapacityLedger` 分开记录普通占用和复读占用。现有 LevelProfile 示例普通同屏名额 24；现有 playable battle config 复读同屏名额 24，队列等待上限 96。
4. `BarrageTraitSet` 已可挂多项兼容特性；`spawn_normal_barrage(level_profile,speech,selected_trait_ids)` 已支持显式传入特性。普通批次当前使用缺省空特性列表，自动随机分配仍需衔接。
5. `AttackChargeInput._capture_target_snapshot()` 对所有子弹幕进行区域相交扫描并冻结多个目标；`AttackTargetSnapshot` 按实例 ID 去重及到达复核。FO 神谕候选有独立的最近目标单选规则。
6. `Sandbox._on_shot_hit_resolution_submitted()` 已基于逐目标结果结束普通话语、负收益话语及复读（遮挡例外），并为真实有效普通话语创建复读计划与倾向记录。
7. `HitResolution` 已汇总有符号目标收益并一次更新 PK；特殊负收益和整发异常惩罚已有接线，当前尚缺独立每发正/负封顶。
8. `RepeatDelayQueue` 已将普通复读按 0.5～3 秒排队，容量满时按既有规则处理请求，实际出现后才进入统计；`clear_normal_queue()` 已存在。
9. `CombatStage` 已处理最终 Tier 0～5、跨档通知、Tier 倍率和 T5 满值后的阶段结果；`Sandbox` 已接入独立的矛盾击破阶段。
10. `SandboxBattleHud` 已有状态文字与对手立绘资源位置，T0 匹配/T1 气泡演出的生命周期尚需接线。

## 原任务与实际代码冲突
1. 旧 BG-16/17 仍描述 500～1000 条普通话语：最新改为每档少量前景与多量背景复读的性能、可读性验收。
2. LC-11 与 Tier 名额的所有权重复：归档 LC-11，改以 CS-24 `CombatStageTierConfig` 为唯一普通战斗 Tier 前景名额来源；原 `LevelProfile.normal_barrage_screen_cap` 作为旧基础值及其他阶段逻辑基线。
3. BG-34、BG-38、CA-14、RP-14/15/18 已有大部分功能：任务转为 Tier 接线、混合遮挡回归、缩放/重叠实测与表现验收。
4. CA-15 是实质功能缺口：当前遮挡与正常话语混合相交时，普通话语仍可能获得收益并被移除；最新确认规则为本发全部按已有 MISS 处罚处理，区域目标留场；需依据 occlusion 特性存在事实判断，兼顾同条弹幕挂多个特性。
5. CS-14 与 CS-18 应在一发完整结算、倾向/复读请求处理完成后清屏和清除本次旧待生成复读；避免清屏时提前触发旧发的复读反馈。
6. RP-16～RP-18 旧的越高 Tier 越快或空间感染方向已改为复读固定慢速向右、随寿命渐隐、灰色底层与同向复读潮。
7. 遮挡弹幕是普通话语挂 `occlusion` 特性，不属于第二种独立实体；特殊上限按带特性的前景**实例**计算，一条挂两个特性也仅占一名额。
8. Paradox 属 T6 的演出标签，而现有 CombatStage 资源仅负责 T0～T5；新增 CS-25 表现接线和 CB-13 固定一真五假六句生成。
9. T0 回拉倍率在 `data/combat_stage/tier_catalog.tres` 当前为 1.1，正式改 0 的工作由 CS-19 仅改数值并验证；既有 OpponentPKBar 接受倍率 0。
10. T1 对手立绘已有展示节点，当前开局就绑定，对应 CS-21 是时机/可见性接线；状态文字已有接口，对应 CS-20 是文案接线。
