## 3. INT-16 / A / D 最小绑定序列

```gdscript
var catalog = BarrageTraitCatalog.new()
catalog.load_production_tables()
var traits = preload("res://systems/barrage_traits/barrage_trait_runtime.gd").new()
traits.bind(barrage_area, catalog) # 普通生成启动之前；只实例化一份
traits.begin_attempt(current_level)
battle_flow.shot_resolved.connect(traits.on_shot_resolved) # 同步，不能 CONNECT_DEFERRED
var tutorial = TutorialStepRunner.new()
tutorial.hint_requested.connect(tutorial_ui.show_tutorial_hint)
tutorial.step_completed.connect(save_completed_step_id) # INT-16 持有当前周目已完成 ID
tutorial.tutorial_completed.connect(on_tutorial_completed) # UI clear_tutorial_hint
battle_flow.shot_resolved.connect(tutorial.on_shot_resolved)
tutorial.begin(current_level.tutorial_config_id, completed_step_ids)
# 每个正常战斗帧：tutorial.observe_combat_frame(barrage_area, aim_reticle, attack_input)
# attempt_started / attempt_restarted：traits.begin_attempt(level)
# 同时 tutorial.begin(level.tutorial_config_id, 当前周目完成 ID 副本)
# 场景结束：traits.unbind()
```
