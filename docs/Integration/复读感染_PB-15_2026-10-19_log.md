## 配置所有权与正式开局

- C 的 population_config.csv 提供 initial_neutral_count=30、initial_seed_slot_count=0、中心间隔0.75秒和jitter ratio 0.25（约0.5625–0.9375秒）。
- PlanBBattleHost.configure_modules() 加载 C 内容目录后，调用 PlanBUnitSimulation.configure_population_config()，把上述配置实际写入 B 模拟器。
- C 的 seed_slot_count=0 表示不额外申请种子槽；A Host 的 initial_opponent_seed_count=2 仍是对手开局播种的唯一来源。Host 显式调用 create_population(-1, 2)，创建30名中立和2个待播种槽；播种后场上保留30名中立。
- 自动补人使用独立随机流；set_random_seed() 同步重置棋子和补人随机流。B 的 neutral_spawn_batch_reserve 默认为可调8，人口到 maximum_population-8 后暂停补人，释放容量后接续。
- 2/4/8整批发表容量仍由实时单位总数和B现有原子批次接口控制；A 的 Host 继续拥有PK与播种事务。
