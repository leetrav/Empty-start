### 首轮发现与修正

1. Windows 标题栏把初始 GPU 帧压到 1920×1055。重播入口使用无边框并显式设定窗口尺寸，低档同时设 content_scale_size；PNG 尺寸逐项断言。只改验收入口，生产窗口样式未改。已新增 KT-43。
2. 直接跳 PK 满而没有普通历史，会在验收夹具中触发空神谕候选错误。每个成功分支先做真实普通攻击，再经原候选流程；未改 B 的候选或阶段规则。
3. 首轮事件列表输出把 Array 当作格式参数列表，发生日志格式错误。修正后两档重新完整运行，最终均无相关错误。早期 `large*` 日志和图不作为最终无错误验收依据。
