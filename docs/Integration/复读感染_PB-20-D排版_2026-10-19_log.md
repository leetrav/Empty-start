# 复读感染 PB-20 Lane D 气泡排版日志

日期：2026-10-19

## 本次实现

主播当前主泡和棋盘复读泡共用实际字体测量出的十个全角汉字文字栏宽度。文字列在泡体内居中，单行左对齐；完整原句自动换行，气泡高度按排版结果增加。复读主框宽度不再由团体人数决定；人数只影响尾巴数量与锚点。保留主播历史缩略泡、P1/P2轮廓、团体发声时序和PB-19的32px模拟半径。

## 主要文件

- \`ui/streamer_bubble_dialogue/streamer_bubble_view.gd\`
  - 新增共享的十汉字字体测量方法，当前主播主泡按该文字栏宽度重排。
  - 明确主泡文字左对齐；字号缩小后按新字号重测，全文溢出仍可滚动。
- \`ui/plan_b/plan_b_unit_field.gd\`
  - 删除团体人数100/150/500px主框规则。
  - 复读泡采用相同10汉字测量宽度、左对齐、全文高度和居中安全区；文本布局缓存覆盖话语、字号和视口变化。
- \`docs/Integration/PLAN-B_V0.6_增量需求优先级与交接_2026-10-18.md\`
  - 当前规则已更新为PB-20文本列规范，明确覆盖旧人数定宽规则。

## 目标场景与验证

- Godot \`4.7.2.stable.steam.ed1daf0bf\`，Windows D3D12 / AMD Radeon。
- 按后续接手要求，仅启动独立 Plan B UI 目标场景；未启动完整 Sandbox 或模拟战斗。
- UI使用生产 \`PlanBUnitField\`、\`StreamerBubbleView\` 与主播侧气泡栈；成员位置由独立布局样本快照提供，词语原句来自正式 \`word_pool.csv\`。
- NotoSansSC 22px下，十汉字文字栏实测220px；主播主泡和复读泡均为220px。复读主框五种组合结果均为244px，独立于5/10/11/25字和1/2/3/8成员。高度65px到98px随换行增加；尾巴数1/2/3/5保持既有映射。
- 样本：\`w_0013\` 5字、\`w_0104\` 10字、\`w_0126\` 11字、\`w_0063\` 最长25字，含404notfound。逐帧画面确认全文可见。
- MCPRuntimeProbe捕获1280×720五张、1920×1080一张；最终独立目标场景运行退出码0，stdout/stderr无错误。
