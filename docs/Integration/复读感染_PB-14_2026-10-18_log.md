- Godot 4.7.2、Windows、同一机器与同一 renderer；固定 5 秒预热，再采样 20～30 秒。
- 同一正式 Plan B 场景、同一游戏阶段、相同人口组成、相同物理 TPS、相同分辨率 / 窗口模式，分别记录优化前与优化后。

- 收集 FPS、平均 / 较差帧时间、Physics Time、Script / Idle 时间、最慢函数及 Visual Profiler 的 CPU/GPU 绘制耗时。保留日志和可由预览脚本生成的截图。
- 96 棋子是初始测量档位，不是最终上限。优化后再对 96 / 128 / 160 / 192 做同场景容量测试，并结合帧时间和棋盘可读性提出建议。
- 按用户对 D 的线程要求不使用 Computer Use / Jackie Windows MCP；Godot GUI Profiler 截图无法通过现有 CLI / 预览脚本取得的部分标 `UNVERIFIED`。
