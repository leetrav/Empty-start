## 实现

- `systems/plan_b/simulation/plan_b_unit_simulation.gd`
  - 增加可调 `target_decision_refresh_seconds`，首值0.1秒；按稳定 `unit_id` 分成6个时间相位，错峰更新目标与同伴方向缓存。
  - 移动积分、真实 Area2D 接触、感染/改口、碰撞反冲和边缘反射仍由每个物理步执行。两次决策之间继续按缓存方向和当前速度移动。
  - 寻敌、威胁、同伴及 PB-11 团体邻接复用同一空间网格；网格首值0.1秒刷新，团体拓扑固定0.2秒刷新。感染/改口只改变棋子事实，拓扑变更合并到下一刷新周期。
  - 新生/离场会在下一物理步重建空间索引。接触分离改为短时增加邻域候选padding，避免碰撞本身把整张网格提升到每物理步重建。
  - 删除接触和感染时的全邻域缓存扫描；目标方向按现有错峰时隙更新，状态变化最迟在下一次0.1秒决策时隙生效。
  - 新增 `unit_physics_positions_updated(unit_ids, previous_positions, current_positions)`，每个物理步发出升序 ID 对齐的 `PackedInt32Array` 和两组 `PackedVector2Array`。位置采用 scene-global 坐标；新生及开局夹具以当前坐标初始化，避免首帧长距离拖影。
  - 边缘反射同步修正方向缓存，保持决策间隔内的连续移动。
- `systems/plan_b/simulation/tests/pb14_decision_smoke.gd/.tscn` 与 `pb14_decision_probe.gd`：定向验证目标更新频率、物理帧位置事件频率、坐标数组连续性、排序及人口事实。
- `_advance_units()` 复用已缓存的方向/意图字典引用，取消每单位每物理步创建的临时结果字典和 `steering_by_id` 哈希表。
- PB-11 smoke 的移动断言等待8个物理帧，按错峰决策时序检查首个团体方向；靠拢样本延长至72帧。
- `docs/Integration/PLAN-B_V0.6_增量需求优先级与交接_2026-10-18.md`：补充决策缓存与物理位置事件契约。

### 后续热点修正（B follow-up）

- 接触重叠分离将空间候选padding增加至 `unit_collision_radius + 0.5`，空间网格仍按0.1秒刷新；新生/离场这类成员集合变化仍会在下一物理步立即重建索引。
- 删除 contact/convert/relay 期间的全邻域失效扫描。单位方向继续按每个 `unit_id` 的0.1秒错峰时隙刷新，变化最多等待本单位下一个决策时隙。
- 团体拓扑刷新固定在0.2秒周期；感染、改口、出生或离场的组变化合并到下一周期，保留即时 `unit_changed`、`word_batch_spawned` 与物理接触事件。
- `_advance_units()` 每物理步把缓存字典引用放入一个索引数组供移动阶段读取，减少每单位结果字典及临时 `steering_by_id` 哈希表分配。
