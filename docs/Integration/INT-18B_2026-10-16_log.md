## 真实故障与最小修复

重试后旧矛盾节点在下一帧已释放，再调用原 `complete_result_presentation(source_system: ContradictionBreakSystem)`，Godot 会在进入函数前报告：`argument 1 (previously freed) is not a subclass of the expected argument class`。原函数体中的来源比较因此没有机会执行。

入口改接 `Variant`，先检查 `is_instance_valid(source_system)` 与当前实例身份，再消费完成事实。合法当前实例行为保持原流程；已释放或其他尝试的来源返回 false。

本地最小复现 `stale-before.stderr` 含真实 Invalid type 错误；该进程因为额外 `--quit-after` 返回 0，未将此退出码视作成功。修复后 `stale-after.stdout` 打印 `freed-source accepted=false` 且 stderr 为空。永久回归放在既有 smoke 的真实十秒超时 / 同 Flow 重试中，明确等到下一帧确认旧节点已释放。
