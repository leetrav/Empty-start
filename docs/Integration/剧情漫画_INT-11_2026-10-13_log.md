## 实现与接口

- `ui/comic/comic_player.gd/.tscn`：共用独立场景，累计分镜、淡入、轻微移动、等比布局；配置非空文本时逐字显示。
- `ComicFrame`：静态拆图、坐标、时长、显现参数、文本位置、逐字速度和音效事件配置。
- `ComicSequence`、`data/comics/opening.tres`、`ending.tres`：分别持有两段静态内容，不保存运行进度。
- ID-12 控制器新增可选 `panel_intervals_seconds` 和 `auto_complete_last_panel`；默认仍为原统一间隔和末格等待点击规则。
- `SceneRouter.goto_comic(kind, record_first_view=false)`：接受 opening/ending，独立于 `goto_ending(EndingSession)`；回看不新建周目。
- Boot 始终进入菜单。MainMenu Start 仍进入取名及爪印演出；ID-13 完成爪印后启动嵌入式 ComicPlayer，正常完成继续身份选择，Esc 返回菜单。MainMenu 新增两个回看按钮。
- SettingsManager 保存应用级 `story/opening_comic_seen`，新周目和恢复音量/显示默认值不清除观看事实。写盘失败保持未观看。
- 任意非重复按键先补全文字，下次推进分镜；左键和触摸支持同样操作。Esc 返回主菜单。明确完成/退出才记录首次观看；异常离树仅清理。
- `AudioManager.create_event_player(event_id, owner_node)`：为场景创建独占声音节点，通过配置与既有 UI/SFX Bus 播放；切页销毁，不影响全局音效池。
- `comic_write` 暂复用现有 Kenney `click_002.ogg`，用于验证逐字声音链路；并非正式书写音效，待正式资源替换。
