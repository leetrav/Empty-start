## 已经实现的功能
- S1成功发表会生成2名玩家信徒；S2/S3分别生成4/8名。PlanBUnit.apply_word_snapshot已能整体替换话语、属性、强度与顺序号；同阵营接触会传播较新的词。

## 本次任务
1. **玩家成功发表S1时**，先完成原有2颗整批生成，随后以成功落点为中心，在**120逻辑像素半径**内寻找本批出生之前已存在的玩家阵营信徒，最多选择**4名**；最近距离优先、距离相同按unit_id稳定排序。
2. 将本次S1整条话语快照、战斗属性、倾向、强度及较新word_order应用到被选中的旧己方棋子，保持阵营、单位ID、位置和生命剩余不变；真实克制和接力逻辑消费新状态。
3. 返回实际rewrite_count及改口ID，发出可被UI/教学消费的真实事件；已有unit_changed/单位快照更新链负责展示。
4. 范围内0名旧友军时照常出生2颗，rewrite_count=0；S2/S3继续4/8颗与现有自然碰撞传播。
5. 作为一次发表事务处理：整批发表成功后触发改口，失败发表保留手牌并保持旧信徒状态。120px设为可调默认值供实机检验。
