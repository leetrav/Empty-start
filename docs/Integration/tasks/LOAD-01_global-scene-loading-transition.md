# LOAD-01 · 全局场景加载过渡

- 来源：用户 2026-10-20 实机反馈，明确要求全局加载画面，而非漫画分镜间过渡。
- Owner：当前优化工作区；分支 `fix/playtest-20261020`，基线 `main 9d195bf`。本次只交本地试玩，后续 PR 以用户确认的目标分支为准。
- 直接文件：`core/autoload/scene_router.gd`、`ui/loading_screen.gd`。
- 已有问题：所有路由同步读取资源后直接替换场景；加载与页面初始化阶段缺少统一遮罩。
- 实现：常驻加载层、后台资源读取、旧场景淡出、新场景就绪后淡入；短加载不额外长时间等待，较慢加载显示动态提示。
- 边界：所有现有顶层路由及 reload 共用；拦截重复请求和输入；暂停状态下可切换；结局显示参数在 ready 后交付；异步失败保留旧页面并提供返回主菜单入口。
- 排除：漫画内部切格、身份场景内分页、战斗阶段演出、感染性能、资源接线与打包。
- 验收：真实 Godot GUI 检查主菜单/身份/房间/正式战斗/暂停重载/结局；检查重复请求、无效路径及异步失败恢复。截图 1280×720，日志与缓存放 D 盘。
