## 本次任务
1. **费米｜分裂**：继续使用现有split，选中存活敌方信徒后生成最多**2名**相同阵营、话语、属性的孩子，实际人数和人口上限由Simulation判定。
2. **奥格尔｜复制／改口反制**：统计目前所有存活玩家信徒各属性数量，选人数最多的玩家属性（并列按type_a→type_b→type_c），取**克制这一主流属性的战斗类型**，选择最多**3名奥格尔现有信徒**整词改口；从当前关合法奥格尔敌方词池中选对应battle_type的**完整词条快照**以保证显示话语与战斗属性匹配。真实更新后继续原有同阵营自然接力。
3. **咕拉｜吞食**：选1名咕拉存活信徒，在其周围**120逻辑像素**内将最多**3名中立观众**直接转化为咕拉阵营、继承该施法者的完整话语和属性；距离最近者优先、相同距离按单位ID。
4. **列巴｜反弹**：给最多**3名列巴存活信徒**各施加一次性反弹保护；受到玩家合法克制感染尝试时优先消耗一次保护、抵挡本次感染并产生真实反馈；使现有玩家侧reflect处理在双方合法攻击中均可复用。
5. 四关技能每次T2/T4窗口各可触发一次本关专属效果；由C按streamer_id请求、A转发，B回报实际作用的目标/人数，D显示当关主播及中文技能名。成功结果驱动原棋子、PK、感染和倾向系统。
6. 真实目标不足时按存在的单位数量生效，人口上限按当前Simulation处理；没有合法目标时返回明确失败，让PB-26的轮次按成功结果裁决。
7. 四关敌方台词及强度以后由用户重新填写：当前话语仅为临时运行内容，保留现有**text＋battle_type＋strength**数据入口，技能持续从当关合法词池读取，不依赖当前台词原文。
8. 四名对手沿用正式棋子头像、UnitField已有光圈/短提示及现有1.2秒前摇，完成最少量视觉联调。
