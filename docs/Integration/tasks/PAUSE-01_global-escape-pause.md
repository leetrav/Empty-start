# PAUSE-01 · 全页面Esc暂停与全屏退出入口

- 用户2026-10-20反馈：结局页Esc无效，全屏后无法打开设置退出；要求所有页面都能打开同一暂停菜单。
- 基线cf013ab；独立分支fix/global-escape-pause-20261020，当前D盘优化工作区。
- 根因：PauseMenu只在Sandbox和开局房间实例化；结局、身份、标题和独立漫画没有实例，漫画还把Esc当作退出剧情。
- 当前任务：SceneRouter在初始页面/scene_changed时补齐缺少的PauseMenu，已有实例复用；统一音乐与漫画暂停；Esc在设置中仅退回暂停面板；转场期间不改变加载暂停状态。
- 非战斗页默认只有继续、设置、返回主菜单；保留Sandbox现有重开和取消攻击指针的接线。
- 验收：六个顶层页面Esc暂停/恢复、无重复菜单、音乐时钟冻结、漫画不跳出；实际全屏结局→Esc→设置→关闭全屏→返回菜单。
- 本地验证与提交，不改用户存档、不打包或推送。
