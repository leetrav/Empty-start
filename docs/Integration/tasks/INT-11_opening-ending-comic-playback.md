## 本次任务

使用美术交付素材制作独立剧情漫画播放场景，在 ID-13 的动机分镜步骤替换占位漫画，并接入主菜单开头／结尾回看入口。

### 1. 正式素材与播放配置

保留以下目录及原文件名：

| 分组 | 当前文件 |
| --- | --- |
| P1 | `0.png`、`1.png`、`2-1.png`、`2-2.png`、`3-1.png`、`3-2.png`、`3-3.png`、`P1.png` |
| P2 | `0.png`、`1.png`、`2.png` |
| P3 | `0.png`、`1.png`、`2.png`、`3.png`、`P3.png` |
| P4 | `1.png`、`最终效果.png` |
| P5 | `0.png`、`1.png`、`2.png`、`3.png`、`P5.png` |
| P6 | `1.png`、`2.png`、`3.png`、`P6.png` |

1. 查看参考视频和实际图片，核对背景、拆图、完整效果图各自用途，不将全部 PNG 简单当作顺序播放页。
2. 用户已确认 P1～P6 均属于同一段开场动画。首次动机漫画按 P1→P6 连续播放；菜单“开头”回看 P1～P4，“结尾”回看 P5～P6，后两幕不是通关结局。
3. 根据确认结果配置图片引用、出现顺序、位置、停留时间、移动、显隐及转场。
4. 开头与结尾共用播放场景，分别读取内容配置；素材缺失时记录具体缺项，不用错误内容代替。

### 2. 漫画表现

1. 按配置时间和顺序自动呈现分镜，参考视频确定画面移动、停顿和转场方式。
2. 剧情文字逐字显示，并配合打字机／手写书写音效。
3. 当前素材尚未确认完整剧情文本，实施前核对正式台词及显示位置；已画入图片的文字需确认如何满足逐字呈现。
4. 图片布局以 1920×1080 为基准适配窗口，保留分镜构图和原素材比例。

### 3. 开场流程与菜单回看

1. 启动始终先进入主菜单。开始游戏 → 主播取名 → 姓名与爪印演出 → 开头漫画 → 身份选择；首次正式漫画替换动机分镜 TEST_ONLY 占位页，连续播放六幕后继续原身份流程；应用已有观看记录则直接进入身份选择。
2. 主菜单增加“再次播放开头”“再次播放结尾”，回看完成后返回主菜单。
3. 顶层场景切换统一通过 SceneRouter。
4. 菜单回看不创建新周目、不修改当前周目存档。
5. 嵌入式播放器复用 ID-12，正式漫画末格支持自动完成；控制器默认末格等待点击规则保持不变。
6. 本卡覆盖身份流程内的完整六幕开场及其两部分菜单回看，不将 P5～P6 接到通关结局。

本节流程以用户 2026-10-13 对启动顺序及“仓鼠动机分镜”接入位置的明确纠正为准。

### 4. 输入与观看记录

以下规则已经用户审核，作为本卡实施依据：

1. 除 Esc 外，任意非重复按键直接跳过整段漫画；首次开场跳过后记录已观看并继续身份选择，菜单回看跳过后返回菜单。左键、触摸采用相同跳过行为。
2. Esc 退出当前漫画并返回主菜单。
3. 观看记录使用应用级持久设置；不控制启动路由，但新周目进入动机步骤时用于直接跳过已观看的完整开场。正常完成、主动跳过或 Esc 退出后记为已观看；异常关闭不记录。
4. 新建或删除周目不重置观看记录。
5. 退出和重播时清理旧计时、动画、音效及输入状态；完成通知只发生一次。

### 5. 音频接入

1. 核对正式书写音效及音频事件配置，使用 AudioManager 的实际公开接口。
2. 音效随文字或对应演出触发，停止播放时及时停止本段音效。
3. 缺少正式音效时在日志中明确记录，不声明音频验收完成。

## 验收条件

1. 无论是否有观看记录，启动均进入主菜单。开头漫画仅在开始游戏并完成姓名与爪印演出后自动播放，完整播放或任意键跳过后进入身份选择；已有观看记录时直接进入身份选择。
2. 开头和结尾菜单入口可重复播放正确内容，回看前后周目数据一致。
3. 分镜顺序、画面动作、逐字文字和音效符合确认后的内容配置。
4. 无操作时自动播放至结束；任意键和 Esc 行为符合审核确定的规则。
5. 正常结束、退出及重播后无旧音效、计时或完成回调残留。
6. 原身份流程可正常推进，ID-12 末格确认行为保持可用。
7. Windows 实际运行下，窗口缩放后图片、文字及交互正常。
8. 保存必要录屏和关键画面，完成漫画节奏、文字可读性及音效听感的人工验收。
9. 未确认的剧情分段、素材缺项及未验证平台如实记录，不声明完整验收通过。
