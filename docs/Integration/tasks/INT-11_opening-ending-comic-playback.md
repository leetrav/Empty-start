## 本次任务

使用美术交付素材制作独立剧情漫画播放场景，首次运行直接播放完整六幕，结束后进入主菜单，并提供前后两部分回看入口。

### 1. 正式素材与播放配置

保留以下目录及原文件名：

| 分组 | 当前文件 |
| --- | --- |
| P1 | `0.png`、`1.png`、`2-1.png`、`2-2.png`、`3-1.png`、`3-2.png`、`3-3.png`、`P1.png` |
| P2 | `0.png`、`1.png`、`2.png` |
| P3 | `0.png`、`1.png`、`2.png`、`3.png`、`P3.png` |
| P4 | `1.png`、`最终效果.png` |
| P5 | `0.png`、`1.png`、`2.png`、`3.png`、`P5.png` |
| P6 | `1.png`、`2.png`、`3.png`、`P6.png` |

1. 查看参考视频和实际图片，核对背景、拆图、完整效果图各自用途，不将全部 PNG 简单当作顺序播放页。
2. 用户已确认 P1～P6 均属于同一段开场动画。首次动机漫画按 P1→P6 连续播放；菜单“开头”回看 P1～P4，“结尾”回看 P5～P6，后两幕不是通关结局。
3. 根据确认结果配置图片引用、出现顺序、位置、停留时间、移动、显隐及转场。
4. 开头与结尾共用播放场景，分别读取内容配置；素材缺失时记录具体缺项，不用错误内容代替。

### 2. 漫画表现

1. 按配置时间和顺序自动呈现分镜，参考视频确定画面移动、停顿和转场方式。
2. 剧情文字逐字显示，并配合打字机／手写书写音效。
3. 当前素材尚未确认完整剧情文本，实施前核对正式台词及显示位置；已画入图片的文字需确认如何满足逐字呈现。
4. 图片布局以 1920×1080 为基准适配窗口，保留分镜构图和原素材比例。

### 3. 首次启动与菜单回看

以用户最新明确指示为准：首次运行 → 完整 P1～P6 动画 → 主菜单。漫画不接入角色塑造的动机分镜步骤；原 ID-13 流程保持原样。

1. Boot 无当前版观看记录时调用 SceneRouter.goto_comic(&"intro", true)，组合前后两份 Resource，共19个播放节点。
2. 完整播放结束或 Esc 退出后进入主菜单；以后启动直接进入主菜单。
3. 主菜单始终提供“再次播放开头”（P1～P4）和“再次播放结尾”（P5～P6）；这里的结尾是开场动画后半，不是游戏通关结局。
4. 回看不创建周目，回看完成或退出仍返回菜单；开始游戏继续原角色塑造流程。

### 4. 快进、退出与观看记录

1. 任意非重复按键快进：有未完文字先补全，否则推进下一分镜；末格结束整段。左键和触摸提供同一入口。
2. Esc 退出漫画返回主菜单，不修改其他页面的 Esc 接线。
3. 当前版使用应用设置 story/opening_intro_v2_seen。旧 opening_comic_seen 试播记录不用于判断新版首次运行，不清除用户角色存档或音量/显示设置。
4. 首次完整播放或主动 Esc 退出记录已观看；异常离树不记录。菜单回看不影响首次记录。
5. 切换分镜、退出及离树停止该场景拥有的动画、打字声与翻书声。

### 5. 免费音效接入

1. 打字声采用 Cassie-OrbitGames 的 Typewriter sounds/typewriter1.wav，CC0；翻书声采用 Kenney RPG Audio/Audio/bookFlip1.ogg，CC0。
2. 资源放 assets/audio/sfx/comic/，来源及许可见同目录 README.md、Kenney-License.txt；通过 AudioManager 的 comic_write / comic_page 事件播放。
3. 翻书声在幕切换时触发。文字配置非空时打字声随逐字显示；未提供正式台词时只在画面显现期间短暂播放打字声，不虚构剧情。
4. 正式台词仍待提供；不声明正式文字演出完整验收。

## 验收条件

1. 首次启动直接播放六幕，自动结束到主菜单；下一次启动直接到菜单。
2. 任意键快进分镜，Esc 退出到菜单，重复按键不误推进。
3. 菜单两部分可重播，周目不改变，开始游戏保持原角色塑造流程。
4. 打字与翻书音效实际加载并播放，退出后无音频残留。
5. 旧试播记录不阻止新版首次播放，音量、显示设置和角色存档保留。
6. 正式台词、动画节奏、黑幕衔接及 Android 人工验收尚待完成，如实记录。
