## 已经实现的功能
- 当前PlanBBattleHost.update_pk已按 k×（己方人数−敌方人数）/总人口×delta 更新，原默认k=0.85；运行时Tier已通过正式外部源驱动。
- 敌人普通反击原来只按人数差≥2触发，1.2秒前摇、25秒冷却、每局最多2次；尚未真正检查技能名的Tier数字。

## 本次任务
1. 在正式Plan B的权威PK计算入口将**k=3.0**定为本次试玩版数值；保留原来的比例计算、上升/下降方向与现有Tier/结算通知，核对导出属性和场景覆盖后的真实生效值。
2. 所有对手的**特殊反击轮次**绑定正式Tier：**首次达到T2／PK≥64%**获得第一轮资格，**首次达到T4／PK≥79%**获得第二轮资格；每轮至多成功执行1次，PK回落后再升保持已消耗状态。
3. 发动反击时要求**玩家现存信徒至少领先对手2人**，距上一轮成功反击**至少25秒**，并播放**1.2秒**正式前摇。保持一局至多两次成功技能。
4. 若提前进入T4，先安排尚未执行的T2轮次，再在冷却和资格满足时安排T4轮次；已经进入过的Tier资格在本局保留。技能缺少可用目标时保留尚未成功的轮次并提供明确结果。
5. 第一关PB-25剧情教学中由实际教程状态暂缓一般特殊反击执行；教学结束按实际PK、Tier、人数资格恢复。教程指定费米✌️发表走普通发表通路。
6. 提供可交给PB-27消费的轮次、当前streamer_id、参数与中文技能名，执行结果回到相同真实反击事件；失败重开重置本局资格、间隔及次数。
7. 最短检查正负人口差下的PK方向、实际k=3.0与T2/T4资格各一次；完整整局时长由后续总控统一试玩，不在本卡增加长时人口模拟或胜率回归。
