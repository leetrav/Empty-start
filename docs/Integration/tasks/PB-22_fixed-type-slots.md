## 已经实现的功能
- 三张玩家话语卡原来共享词池随机抽取，每槽成功发表后独立5秒补牌；word_id本局使用一次。
- 词条均包含battle_type与strength，A/B/C分别映射✊石头／✌️剪刀／✋布，强度S1/S2/S3对应2/4/8名新棋子。

## 本次任务
1. 固定 **槽1=type_a/✊铁拳布道、槽2=type_b/✌️断章取义、槽3=type_c/✋博爱包容**，在初始发牌、成功使用、独立5秒补牌和重开后均成立。
2. 每个槽从对应属性的本关玩家合法词池中随机抽词，强度随被抽词的strength取S1/S2/S3，**继续随机**；默认按真实可用词条抽取，无需强制三种强度等概率。
3. 持续使用本局已用word_id排除、同手牌ID去重；失败发表保留卡；槽位词池用尽时该槽显示无词可抽，其余槽照常运作。
4. 在现有抽牌函数上支持**第一关教学一次性指定✋槽合法S1**；教学使用后恢复该槽正常随机补牌。直接复用现有词池与槽位接口，避免额外卡池、存档字段或随机系统。
5. 更新三槽权威状态以供PB-24准确渲染克制符号及强度名称。
