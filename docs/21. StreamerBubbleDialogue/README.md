# 21. StreamerBubbleDialogue 双主播气泡对话系统

## 系统目标
在玩家和对手主播立绘周围显示可随事件出现的漫画式说话气泡。气泡文本按触发顺序逐条上浮，所有视觉资源由美术提供可替换素材。此系统只持有对白事件、待显示队列和气泡生命周期，**命中结算、Tier、输赢、PK 与正式剧情状态由现有系统提供**。

## 系统边界
- **立绘区域**：玩家和对手各有自己的主播画面，气泡出现于对应立绘四周，随当前画面尺寸适配。
- **内容来源**：普通有效命中的原句可直接作为气泡显示；指定原句还可以触发对手配置好的台词。
- **对手触发**：①指定话语实际命中；②连线、输赢、升降 Tier 等既有状态事件；③本场战斗进行中的时间节点。
- **多条顺序**：按事件与实际逐目标命中记录的到达顺序上浮，由统一队列管理。
- **已有系统复用**：CS-22/T1 开场对白、CS-27/Tier 降档嘲讽由对应阶段事件调用本系统；对手登场、离线与战斗回拉逻辑仍属于 08 系统。
- **素材**：美术绘制气泡背景和字体风格；程序提供双侧位置、上浮动画、文字装载和替换资源入口。

## 需要策划后续确认
1. 普通命中话语默认映射到玩家气泡、对手气泡还是由话语来源确定；暂由配置指定说话方。
2. 一发多目标时的队列最大长度、单条气泡停留时长和冲突事件是否有抢占优先级。
3. 复读命中、假牌、反弹等特殊结果是否像普通原句一样触发复述；以最终有效命中事实为入口，具体可视范围待确认。
4. 对手在 T0 离线期间是否仍有时间对白；本轮只规定正常战斗的有效计时输入。
5. 具体对白文本、立绘周围气泡造型与动画速度，由策划及美术交付。

## 派工建议
先做 SD-01～03 的可复用显示能力；SD-04、05、06、07 作为互不重写 HUD 的事件消费者分别接线。阶段系已有卡片继续负责自己的触发条件，保持事件流单向。
