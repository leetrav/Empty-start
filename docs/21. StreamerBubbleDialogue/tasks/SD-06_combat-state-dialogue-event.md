## 本卡唯一功能
根据连线、Tier、输赢状态播放配置对白。

## 触发条件
发生对手连线、Tier 升降、战斗胜利或战斗失败等已定义的状态事件时。

## 应发生的行为
接收现有 CombatStage、Sandbox 以及 CS-22/CS-27 等入口发出的状态事实，按策划配置的事件 ID、当前对手及文本选择需要显示的关键剧情气泡，并提交 SD-03 的高优先级队列，保证关键剧情对白逐句播完。T1 开场对话的完整播放结果提供给 CS-23 使用。

## 验收
进入 T1 可播放当前对手开场气泡；降至 T1 可播放嘲讽；升降其他 Tier、胜负结果可按配置显示对应台词；T1 开场结束通知在完整展示后准确发出，关键剧情不会被普通命中和定时气泡打断。
