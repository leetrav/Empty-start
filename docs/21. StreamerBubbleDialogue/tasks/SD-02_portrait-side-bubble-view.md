## 本卡唯一功能
在双主播立绘四周绘制上浮气泡。

## 触发条件
左侧玩家主播或右侧对手主播收到一条应展示的气泡内容时。

## 应发生的行为
在对应主播立绘附近生成**传统椭圆形漫画对白气泡**，使用 Godot `Control._draw()` / `StyleBox` 等绘制椭圆底板、深色描边、指向当前说话主播的可左右翻转的尖尾；文字使用 `RichTextLabel` 自动换行并根据文本长度适当调整气泡宽高。气泡短促弹出，再随对应主播区尺寸适配向上浮动、渐隐并在配置寿命结束后退出。同侧多条按原有队列顺序排布并允许同时显示；描边颜色、填色、尾巴位置、最大宽度、文字边距和动画时长集中可调。使用程序美术提供正式气泡背景，不依赖新增 PNG；正式字体到位后通过现有 Theme 替换。基准 1920×1080 三列 HUD 并兼容窗口缩放。

## 验收
玩家和对手两侧显示椭圆漫画气泡，尖尾分别指向正确主播；长短文字自动排版，上浮 / 淡出正确。同侧多条按队列展示，场上弹幕与准心正常运行，调色 / 边距 / 尾巴方向能独立调整。
