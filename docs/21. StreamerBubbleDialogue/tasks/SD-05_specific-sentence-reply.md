## 本卡唯一功能
击中特定话语触发对手预设对白。

## 触发条件
一发攻击的真实命中事实包含策划配置的目标原句 ID 时。

## 应发生的行为
用稳定原句 ID 查询对应对手对白条目，把匹配的对手气泡作为对应的关键对白请求交给 SD-03，依照当前剧情优先级顺序显示；玩家侧仍可通过 SD-04 复述被命中的原句。对白正文与触发原句的映射由策划数据配置。

## 验收
为一条指定原句配置对手答话后，真正命中该句会在对手立绘旁出现对应台词；其他原句仍按现有 SD-04 规则映射。
