## 本卡唯一功能
双主播气泡对白的数据配置。

## 触发条件
策划为本场玩家或对手设置气泡台词及触发方式时。

## 应发生的行为
提供可编辑的气泡对白条目，记录发言方（玩家或对手）、显示文本、关联的稳定话语 ID（如适用）、事件类型和展示时长。场景与后续任务卡通过明确的条目读取和事件请求入口取得对白，不重新保存 PK、Tier 或命中历史。

## 验收
不同玩家/对手台词可以通过独立条目读取；按原句 ID 与事件 ID 查到正确配置。
