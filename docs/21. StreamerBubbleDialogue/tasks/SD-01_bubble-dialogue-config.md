## 本卡唯一功能
双主播气泡对白的数据配置。

## 触发条件
策划为本场玩家或对手设置气泡台词及触发方式时。

## 应发生的行为
提供可编辑的气泡对白条目，记录发言方（玩家或对手）、显示文本、关联的稳定话语 ID（如适用）、事件类型、展示时长和显示优先级（关键剧情 / 即时命中 / 定时闲聊）。普通实际命中的非复读话语默认分配到玩家侧；指定话语对手答话使用策划明确指定的对手侧。场景与后续任务卡通过明确的条目读取和事件请求入口取得对白，不重新保存 PK、Tier 或命中历史。

## 验收
玩家/对手对白可按原句 ID 和事件 ID 读取；优先级和停留时间可编辑；普通命中默认映射到玩家气泡。
