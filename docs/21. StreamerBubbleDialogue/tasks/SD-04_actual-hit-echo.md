## 本卡唯一功能
将实际击中的话语映射为主播气泡。

## 触发条件
普通战斗一发攻击完成实际命中结算，并返回逐目标命中事实时。

## 应发生的行为
从现有 Sandbox/HitResolution 的逐目标事实获取原句 ID 和可显示文本，为每条实际命中的话语请求一次主播气泡；按发内真实记录顺序提交 SD-03。发言侧通过已配置的映射读取，支持玩家与对手两侧。以 CA-15 的整发遮挡落空最终事实作为事件输入。

## 验收
一次有效群体命中多条话语时，按真实顺序出现映射原句的上浮气泡；整发遮挡落空沿用落空结果；文本及 ID 与实际击中目标对应。

交付本卡对应的代码修改、Godot 实际运行结果及日期日志；同步更新本系统 README。
