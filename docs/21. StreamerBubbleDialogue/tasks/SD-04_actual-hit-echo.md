## 本卡唯一功能
将实际击中的话语映射为主播气泡。

## 触发条件
普通战斗一发攻击完成实际命中结算，并返回逐目标命中事实时。

## 应发生的行为
从现有 Sandbox/HitResolution 的逐目标事实获取原句 ID 和可显示文本，为每条**实际命中的非复读话语**请求一次玩家侧即时气泡，内容复述该目标实际原句，包含普通正向命中及确实命中的负向效果话语；按整发逐目标结果顺序提交 SD-03。普通复读命中只保留现有结算与反馈；整发被 CA-15 遮挡判为落空时，依照最终落空事实处理。对手专属答话由 SD-05 额外接入。

## 验收
一次有效群体命中多条非复读话语时，在玩家侧按真实顺序出现对应原句气泡；误击的非复读错误话语如确实被命中，也复述其原句；普通复读命中没有此类气泡；遮挡导致整发落空时不生成命中复述；文本与实际目标 ID 对应。
