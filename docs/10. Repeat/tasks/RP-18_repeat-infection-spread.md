## 本卡唯一功能
有效命中形成同向复读潮。

## 触发条件
一句普通话语有效命中并产生多个复读请求时。

## 应发生的行为
同一句原文的复读依照既有计划陆续从左侧出现，并向右缓慢流动，形成对应这一枪的背景复读潮。

## 验收
同句复读从左向右形成潮流，各条保留原句 ID 及实际生成计数。

## 交付
提交与本卡功能对应的变更及 Godot 实际运行结果，维护本系统 README 和本卡完成日志。
