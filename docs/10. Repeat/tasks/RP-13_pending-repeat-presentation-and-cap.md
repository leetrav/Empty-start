# RP-13 复读独立容量、普通文本与分档差异（需求暂存）

**状态：需求收集中 / 未完成 / 暂不派工**

> 本卡仅记录策划已确认的需求和待讨论的设计方向；暂不规定具体节点、渲染器、文字效果算法及数值实现。后续可拆分给 10 Repeat、03 BarrageGeneration 与 08 CombatStage 的 Agent。

## 已有能力
- 复读已有**独立的同屏容量**与**待生成普通复读容量**；默认的同屏复读上限为 24 条，等待容量由调用方数值配置决定。
- 普通命中时按结算后 Tier 生成复读计划，计划保存原句 ID、显示文本、数量、生成档位及寿命。
- Tier 0～5 当前每次普通命中计划复读数量依次为 3 / 6 / 8 / 12 / 15 / 20；这是当前资源配置，不等于本次已确定的最终调整方案。
- 已实际生成的复读有独立统计及相关历史，并可被正常攻击流程查询。

## 已确认的新需求
1. **复读拥有区别于普通弹幕的独立数量上限**。在普通弹幕未来可能达到 500～1000 条的情况下，复读仍要单独限制；最终上限需再次评估，不能简单地与普通弹幕共享额度。
2. **复读文本使用普通文本，不使用富文本。** 第 03 系统已确认普通话语需要富文本混合样式、局部文字动画；复读作为另一类显示对象，保留简洁纯文本显示。
3. **不同 Tier 的复读在表现上需要变化**。随着档位提高，应能察觉复读状态不同；具体采用尺寸增大/减小、速度变化、密集度差异或其他变化方式，**尚未定案**。
4. **复读变化尽量不影响正常弹幕**。复读的显示规则与数量控制应能独立配置/调节，避免挤占普通弹幕预定的容量及改写普通弹幕的样式或运动规则。
5. 复读视觉差异属于表现需求，不改变原句 ID、实际生成事实、复读统计、命中属性或既有奖励规则。

## 待比较的候选方向（尚未经策划确认）
- **倾向建议：高档位复读变得更小、更多、流动更快，但仍是普通文本。** 这样复读能够表达狂热蔓延，也尽量给正常话语留出观察空间。
- 与该方向相反的「高档位复读逐渐变大、增强压迫感」也是备选，但可能挡住更多普通弹幕；暂不写成已确定规则。
- 可以优先利用 Tier 复读数量已有增长来表达阶段变化，再决定是否叠加尺寸/速度/透明程度变化。

## 待后续确认
1. 500～1000 条普通弹幕时，复读的正式同屏上限和待生成队列上限各为多少；是否随 Tier 改变，普通复读与矛盾复读是否分开限额。
2. T0～T5 每个档位的具体文字尺寸、缩放、速度、寿命和显示优先级；变化是否只作用于新生成复读。
3. 复读是否参与 03 系统新增的四种运动模式、区域内部出生和动态前后层级变化；各项是否与普通话语不同。
4. 高密度群体命中产生大量复读计划时，实际生成数与排队数量怎样满足独立容量，同时保持真实有效命中结算；具体与 06、10 再行讨论。
5. CS-13 升档清屏时，已经显示的复读与尚待生成的复读分别如何处理，既有生成统计如何保持正确。
6. 普通文本复读的最终外观与特殊阶段复读是否统一规则。
