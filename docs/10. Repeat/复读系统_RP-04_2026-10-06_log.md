# 复读系统 RP-04 任务日志（2026-10-06）

## 1. 本次任务

让普通复读计划进入等待队列，并按每条复读各自的等待时间逐步返回可生成请求。

## 2. 修改文件

- `core/repeat/repeat_delay_config.gd` 与 `.uid`、`data/repeat/repeat_delay_config.tres`：新增可编辑的延迟范围配置，当前按任务起点设为 0.5～3.0 秒。
- `core/repeat/repeat_delay_queue.gd` 与 `.uid`：新增普通复读等待队列；入队时按计划数量拆成单条计划副本，为每条抽取并记录独立等待时间；`advance(delta_seconds)` 返回已到期的单条请求计划。
- `docs/10. Repeat/README.md`：记录延迟配置 Resource 和队列入口。

## 3. 当前能力

调用 `RepeatDelayQueue.enqueue_plan(plan)` 会为普通复读计划的每个条目各抽一个配置范围内的延迟，写回计划的 `wait_offsets_seconds` 并逐项排队。每帧或按当前流程调用 `advance(delta_seconds)`，到期项会以 `planned_repeat_count = 1` 的计划副本返回，保留原句、模板文本、档位和寿命。

延迟使用 `data/repeat/repeat_delay_config.tres`；队列只管理等待和请求数据，不创建弹幕实例。
