# 弹幕生成系统 BG-01 任务日志（2026-10-05）

## 1. 本次任务

定义单条弹幕的最小运行时数据记录，区分静态话语定义与场上实例数据。

## 2. 主要文件与接口

- `systems/barrage_generation/barrage_runtime_record.gd`：新增 `BarrageRuntimeRecord`，继承 `RefCounted`。
- `docs/3. BarrageGeneration/README.md`：记录字段来源与当前边界。

运行时字段：文本、来源稳定 ID、倾向 ID、强度、稳定 `original_sentence_id`。本卡没有加入普通 / 陷阱 / 复读 / 矛盾类型字段，因为当前无运行逻辑需要按类别分支。

## 3. 当前能力

后续生成代码可创建记录并读取内容文本、来源 ID、倾向 ID、强度和原句 ID。直接关卡话语的来源 ID 可取 `LevelProfile.streamer_id`；倾向 ID 继续由话语定义提供。强度默认 `0.0`，真正使用前由创建方按正式参数赋值。
