# 弹幕生成系统 BG-04 任务日志（2026-10-06）

## 1. 本次任务

普通生成开启期间，按当前关的基础批次数量和批次间隔持续生成普通弹幕。

## 2. 主要文件与接口

- `systems/barrage_generation/barrage_area.gd`：增加 `start_normal_generation(LevelProfile)` / `stop_normal_generation()` 与内置 `Timer` 批次循环；每批调用 BG-03 的 `spawn_normal_barrage()`。
- `systems/barrage_generation/barrage_area.tscn`：加入 Timer 节点。
- `scenes/sandbox/sandbox.gd`：进入 Sandbox 时启动当前关普通生成原型。
- `scenes/sandbox/sandbox.tscn`、`barrage_area.tscn`：更新原型标签。
- `docs/3. BarrageGeneration/README.md`：记录启动/停止 API 和当前边界。

## 3. 当前能力

启动后立即按 `base_batch_count` 生成首批，之后按 `base_spawn_interval_seconds` 重复生成；停止后不再生成新批次，在场视图继续移动。示例关当前使用 3 条/批、1.0 秒间隔、100 像素/秒、普通上限 24 条，均待策划实测。

目前调用入口由 Sandbox 演示；真正战斗阶段尚未接入。因为同屏上限与寿命移除仍未实现，连续生成时话语可能重叠。

## 4. 验证

- 使用 Godot `4.7.2.stable.steam.ed1daf0bf` 执行 headless Editor 扫描，退出码为 0。
- 临时 headless smoke 使用 2 条/批、0.1 秒间隔：初始 2 条，运行 0.35 秒增至 8 条；调用停止后再等 0.25 秒仍为 8 条，退出码为 0。
- Godot D3D12 Movie Maker 运行 Sandbox 90 帧，画面持续显示弹幕；确认生成节奏。单条阅读性仍受未实现的上限和移除规则影响。
- 本卡未新增单元测试；Godot-MCP-Native 当前不可用，使用 Godot CLI 验证。
