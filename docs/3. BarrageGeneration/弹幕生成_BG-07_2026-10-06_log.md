# 弹幕生成系统 BG-07 任务日志（2026-10-06）

## 1. 本次任务

让普通话语和陷阱等普通容量占用者共享当前关卡的普通弹幕上限。达到上限时暂停批次生成，容量释放后恢复。

## 2. 改动文件

- systems/barrage_generation/barrage_area.gd：读取普通弹幕上限；普通视图创建时登记占用，Node 离树时自动释放；提供 try_register_normal_capacity_occupant() / release_normal_capacity_occupant() 给其他普通容量占用者；容量满时暂停 Timer，释放后恢复。
- systems/barrage_generation/normal_barrage_capacity_ledger.gd：用对象实例 ID 统一维护普通容量占用。
- systems/barrage_generation/barrage_view.gd：将 setup() 参数名调整为 barrage_record，规避 KT-26 的 headless 脚本加载问题，运行行为不变。
- tests/barrage_generation/test_normal_and_trap_share_capacity.gd：验证普通话语与陷阱占位共享上限。
- tests/barrage_generation/test_capacity_release_resumes_generation.gd：验证释放槽位后可继续登记普通弹幕。
- docs/3. BarrageGeneration/README.md：补充 BG-07 状态、容量接口和生命周期边界。

陷阱测试使用 RefCounted 占位对象，不实现 BarrageTraits 规则；没有新增或调整 Scene。

## 3. 当前能力

普通话语和陷阱等普通占用者都进入同一容量账本。普通视图加入账本时占一格，Node 离树自动归还；其他占用者通过公开登记与释放入口加入。满额时新的普通生成返回空并暂停 Timer；容量释放后 Timer 恢复。
