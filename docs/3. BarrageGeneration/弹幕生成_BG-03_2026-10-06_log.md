# 弹幕生成系统 BG-03 任务日志（2026-10-06）

## 1. 本次任务

将一条 BG-02 选中的普通话语创建为可见、会移动的场景实例，并让实例持有 BG-01 运行时记录。

## 2. 主要文件与接口

- `systems/barrage_generation/barrage_view.gd` / `barrage_view.tscn`：显示文本并按输入速度向左移动。
- `systems/barrage_generation/barrage_area.gd` / `barrage_area.tscn`：新增 `spawn_normal_barrage(LevelProfile, LevelSpeech)`，构造 `BarrageRuntimeRecord` 并挂载视图。
- `scenes/sandbox/sandbox.gd` / `sandbox.tscn`：Sandbox 启动时读取当前关、抽取一条话语并生成预览。
- `docs/3. BarrageGeneration/README.md`：记录组件入口和原型边界。

## 3. 当前能力

Sandbox 进入时会生成一条样例普通弹幕。实例可读取显示文本、来源主播 ID、倾向 ID、强度和稳定原句 ID；移动速度读取当前关基础参数。运动采用最小的右向左水平移动，因为当前设计还没有指定轨迹。

强度暂用 `1.0` 作为原型值；Sandbox 是当前项目游戏入口，尚无独立的正式战斗舞台。
