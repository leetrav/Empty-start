## 本卡唯一功能
限制携带特性的前景实例数量。

## 触发条件
准备生成带一项或多项特殊特性的普通话语时。

## 应发生的行为
使用既有 BarrageTraitSet 向普通话语实例挂载兼容特性，并让该实例分别占用一个前景名额与一个特殊实例名额。

## 验收
特殊实例上限为 1 时同时最多一条带特性的实例；其 TraitSet 可以有两项兼容特性。

## 交付
提交与本卡功能对应的变更及 Godot 实际运行结果，维护本系统 README 和本卡完成日志。
