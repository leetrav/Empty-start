## 当前已实现的基础
BarrageView 当前继承 Label，仅有整条文字设置；富文本展示要与复读的纯文本区分。

## 本卡唯一功能
普通前景话语支持单句局部富文本样式。

## 触发条件
普通前景话语文本具有局部样式配置时

## 应发生的行为
同一句话的不同文字片段分别显示字体、字号、颜色和强调样式；内容原句 ID 和文字事实继续由 BarrageRuntimeRecord 提供。

## 验收
同一句话可以同时展示多个局部文字格式，内容 ID 与实际显示正文正确。
