## 1. 本次任务

实现纯逻辑主播名确认：空字符串或纯空白采用集中配置的默认名，其他输入原样保留。

## 2. 修改文件

- `core/identity/identity_name_rules.gd` 与 Godot 生成的 `.uid`：新增 `IdentityNameRules.confirm_streamer_name()`，默认主播名集中为 `DEFAULT_STREAMER_NAME`。

- `docs/1. Identify/README.md`：记录确认规则与临时默认名。

## 3. 当前能力

调用 `IdentityNameRules.confirm_streamer_name(input_name)` 可以取得本周目实际使用的主播名。空字符串以及只含空格、制表符、换行的输入回退到“新主播”；有内容的输入完整保留，包括输入两侧空格。

“新主播”是临时默认文案，等待正式策划文案替换。此卡没有接入输入框或存档。

## 4. 验证结果

- 新增并运行两项单元测试：空白回退（覆盖空串和纯空白）、正常名字保留；全部通过。
- Godot 4.7.2 对逻辑脚本执行 `--check-only --script res://core/identity/identity_name_rules.gd` 解析检查，退出码为 0。
- Godot 4.7.2 执行 `--headless --path . --script tests/unit/identity_name_rules_test.gd`，两项测试通过，退出码为 0。
- 使用 Godot `String.strip_edges()` 将空白输入归类为空名；官方文档说明其会剥除首尾空格、制表符和换行：[String](https://docs.godotengine.org/en/4.7/classes/class_string.html)。
