# 三项倾向系统 TT-13：Neutral 普通闲聊接入

## 本次完成

- 基于 `w7775p/main` 的 `112b4ea` 在独立 `feature/tt-13-neutral-speech` 分支实现，保留原 CB 分支和用户本地未提交文件。
- `LevelSpeech` 接受 `tendency_id = "neutral"`，新增内容强度 `strength`（默认 1）；`LevelProfile.neutral_ratio` 默认 0。未配置 neutral 的关卡继续只按原三项生成。
- `NormalSpeechSelector` 按 neutral 比例和单句 `appearance_weight` 选择内容；`BarrageArea` 从 `LevelSpeech.strength` 复制强度，普通弹幕保留 neutral 类别。
- 普通命中继续获得对应强度 PK 收益、普通历史、复读和直播表现；`HitResolution.calculate_normal_word_reward(strength, tendency_id)` 对 neutral 输出 `tendency_delta = 0`。`TendencyState` 三项数值因此不变化，只命中 neutral 仍是全零有效状态。
- `RepeatPlan.tendency_id` 保存原句类别，Sandbox 创建普通复读计划时传入，复读弹幕保留 neutral 原句 ID 与类别。
- `FinalOracleCandidatePool` 仅接受正统、异端、荒谬历史进入神谕/圣典候选；为尚未实现的神降临 DD-02 提供 `DivineDescentCandidateFilter.filter_three_tendency_history()`，使已提交普通历史中的 neutral 在未来候选归并前被排除。

## 主要文件与接口

- 数据：`data/level_configuration/level_speech.gd`、`level_profile.gd`。
- 生成与复读：`systems/barrage_generation/normal_speech_selector.gd`、`barrage_area.gd`、`core/repeat/repeat_plan.gd`、`scenes/sandbox/sandbox.gd`。
- 结算与筛选：`core/combat/hit_resolution.gd`、`systems/combat_attack/attack_charge_input.gd`、`core/final_oracle/final_oracle_candidate_pool.gd`、`core/divine_descent/divine_descent_candidate_filter.gd`。
