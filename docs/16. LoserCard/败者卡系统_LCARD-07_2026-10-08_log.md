## 3. 当前能力与数据归属

- `get_acquired_cards(catalog) -> Array[Dictionary]` 按获得顺序返回周目全部已获卡片，空历史返回 `[]`。
- `get_new_card_for_level(level_id, catalog) -> Dictionary` 读取该关实际成功发出的卡片，未成功发卡返回 `{}`；同主播跨关重报、未击破、无资料导致发卡失败均保持无新增。
- 卡片快照形状为 `{"streamer_id": StringName, "profile": LoserCardProfile 或 null}`。返回容器和 Profile 的修改不会回写 LoserCardData 或静态 Catalog。
- 已发卡而当前缺少资料时，保留获卡 ID 并返回 `profile = null`，供 Rest 区分资料缺失与本场无新增。
- 现有发卡入口每次成功同时追加 `rewarded_level_ids` 与 `acquired_streamer_ids`，查询以同索引读取来源对应关系，读档后继续适用。没有增加第二份来源映射或临时奖励状态。
